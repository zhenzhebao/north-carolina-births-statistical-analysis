# North Carolina Births Statistical Analysis

## Introduction

This project begins by presenting various visualizations to help the audience better understand the characteristics of 800 mothers and newborns from North Carolina in 2004. Selected subsets of the records are then used to investigate whether pregnancy duration and the proportion of low-birth-weight newborns differ between mothers in two different age groups, and whether male and female newborns have different average birth weights. The project concludes with a purposefully designed presentation intended for both technical and nontechnical audiences, with an appropriate level of technical detail.
